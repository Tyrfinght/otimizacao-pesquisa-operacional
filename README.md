# Otimização e Pesquisa Operacional

## Projetos Desenvolvidos

* **[Alocação de Aulas (Case IMECC-Unicamp)](./alocacao-aulas-imecc/):** Otimização de *timetabling* e escala de recursos humanos usando Programação Inteira (PuLP) para designar professores, turmas e horários sob restrições rígidas.
* **[Otimização de Trânsito e Gargalos (Rodovia SP-065)](./otimizacao-fluxo-sp065/):** Análise viária e simulação de capacidade logística utilizando a Teoria dos Grafos e Algoritmos de Fluxo Máximo (NetworkX).
* **[Algoritmo Primal Simplex (Construção from scratch)](./algoritmo-primal-simplex/):** Implementação matricial do método Primal Simplex, utilizando puramente NumPy, para a resolução de Problemas de Programação Linear.

## Tecnologias Utilizadas
* **Linguagem:** Python
* **Bibliotecas:** NumPy, PuLP, NetworkX
* **Matemática:** Álgebra Linear, Grafos, Pesquisa Operacional
